# Top 300 BR - Xbox 360

Site estatico para acompanhar progresso da lista Top 300 BR.

Nome recomendado do repositorio:

```text
top-300-xbox-360-br
```

Arquivo HTML principal recomendado:

```text
index.html
```

Neste projeto, `index.html` ja existe e abre a lista principal. O arquivo `top_300_br.html` fica mantido como nome descritivo interno.

## GitHub Pages

Publique esta pasta como repositorio proprio no GitHub.

Configuracao recomendada:

- Branch: `main`
- Source: `Deploy from a branch`
- Folder: `/ (root)`

O arquivo `index.html` redireciona para `top_300_br.html`.

## Persistencia

O progresso fica salvo no navegador via `localStorage`, na chave:

```text
top300GameState
```

Use os botoes `Exportar` e `Importar` para transportar o progresso entre navegadores ou dispositivos.
